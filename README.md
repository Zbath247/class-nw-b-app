# Class_NW_B Web App

A simple university/classroom dashboard using:
- HTML5
- CSS3
- Vanilla JavaScript
- Google Sheets (Database)
- Google Apps Script (Backend API)
- GitHub + Vercel (Deployment)

## Setup Steps

1. Create Google Sheet named **Class_NW_B_Database** with tabs (Students, Attendance, Subjects, etc.).
2. Open Google Apps Script → connect to the Sheet.
3. Write API functions (GET, POST, PUT, DELETE).
4. Deploy Apps Script as Web App → copy URL.
5. Paste URL into `script.js` → `const API_URL`.
6. Upload project files to GitHub.
7. Connect GitHub repo to Vercel.
8. Deploy → test online.
